# 决策档案: Search 表面复用巩固阈值作为硬预算

Status: implemented

## Problem

自动巩固只在轮末异步触发。模型缓慢、拒绝合并或宿主继续收轮时，Search 返回给宿主的 depth-1 话题仍会持续增长，不能把“有自动压缩”误当成“注入上下文有界”。

## Decision

巩固阈值为正时，搜索读口将同一阈值同时作为一层话题表面硬预算，仅返回最新话题，并以响应中的省略计数说明未纳入本次答案的旧话题数量。完整转录读口不受该预算影响，省略不等于删除。负阈值是宿主同时关闭自动巩固与表面预算的显式写法。

## Alternatives considered

- 只依赖 Dream：保留全部表面语义，但慢/失败/关闭时没有硬上界。
- 静默截断：实现最少，却让宿主无法区分“旧记忆被省略”与“旧记忆不存在”。
- 新增独立 Search 配置旋钮：能分开调触发与预算，但两个数描述同一表面，默认会形成需要反复对账的第二套词汇。
- 限制 SceneContext：会牺牲完整原文回看，超出“限制 prompt 注入”的目标。

## Consequences

- 换来：无论自动巩固正常、缓慢或失败，注入宿主上下文的话题表面都有硬上界；保留最新项并用省略计数让宿主区分“旧记忆被省略”与“旧记忆不存在”，完整原文仍可另行读取。
- 代价：超预算期间旧话题不进入提示词，宿主需要利用省略计数解释答案或改用完整读取。
- 放弃：不新增独立搜索预算旋钮，也不截断完整转录；复用阈值意味着调低它会同时提高巩固频率并缩小提示词表面，两项行为必须作为同一配置语义理解。
